
# EventosUSFA

## Descripción
Proyecto de práctica de HTML semántico y accesibilidad inicial.
Se desarrolla un catálogo de eventos universitarios y una página
de detalle utilizando elementos semánticos de HTML.

## Archivos
- index.html: catálogo de eventos.
- libro.html: ficha de detalle de un evento.

## Ejecución
Abrir index.html en un navegador web para visualizar el catálogo.
Desde el catálogo se puede acceder a la ficha del evento.
